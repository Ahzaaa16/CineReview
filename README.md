# CineReview

CineReview adalah aplikasi sederhana berbasis bahasa Go (Golang) untuk mendata dan memberikan ulasan pada daftar film favorit.  
Aplikasi ini dibuat untuk memenuhi tugas besar mata kuliah Algoritma dan Pemrograman.

# Deskripsi Program

CineReview digunakan untuk:
- Menambahkan dan mengelola data film
- Mencari film berdasarkan judul atau genre
- Mengurutkan data film berdasarkan rating dan tahun rilis
- Memberikan informasi rating film
